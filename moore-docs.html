1. Problem Definition & Specification

Problem Statement

Automata theory is a fundamental topic in computer science, yet most students struggle to understand finite-state transducers — particularly the conversion between Moore and Mealy machines — because existing tools lack step-by-step visual explanations. Students need an interactive simulator that shows exactly how the conversion algorithm works, one transition at a time.

Project Objective

Build Automata Lab, a browser-based educational simulator that allows students to:

  • Define a Moore machine using a form, text editor, or by loading a preset.
  • Validate the machine with detailed error and warning messages.
  • Execute the Moore→Mealy conversion algorithm step by step, with pseudocode highlighting.
  • Inspect the resulting Mealy machine's graph and transition table.
  • Simulate both machines on custom input strings and verify the n+1 vs n output property.
  • Practice conversions with quiz mode and random machine generation.

Inputs and Outputs

Inputs
  • Set of states Q
  • Input alphabet Σ
  • Output alphabet Δ
  • Initial state q₀
  • State output function λ: Q → Δ
  • Transition function δ: Q × Σ → Q
Outputs
  • Equivalent Mealy machine M' with λ': Q × Σ → Δ
  • Step-by-step conversion trace
  • Moore and Mealy transition tables
  • Interactive SVG graph of both machines
  • Output strings for test inputs
  • Equivalence verification

Formal Definitions

Moore Machine: M = (Q, Σ, Δ, δ, λ, q₀)
  δ: Q × Σ → Q  |  λ: Q → Δ

Mealy Machine: M' = (Q, Σ, Δ, δ, λ', q₀)
  δ: Q × Σ → Q  |  λ': Q × Σ → Δ

Conversion rule: ∀q∈Q, ∀a∈Σ: λ'(q,a) = λ(δ(q,a))

4. Algorithm & Correctness

Algorithm Selection Rationale

The standard Moore-to-Mealy conversion is the only known algorithm for this problem. It runs in O(|Q|·|Σ|) time and requires no extra states, making it both optimal and simple to implement and explain.

Pseudocode

ALGORITHM MooreToMealy(M = (Q, Σ, Δ, δ, λ, q₀))
 1. Q' ← Q ; Σ' ← Σ ; Δ' ← Δ ; q₀' ← q₀ ; δ' ← δ
 2. Create empty table λ': Q × Σ → Δ
 3. FOR each state q in Q:
 4. FOR each symbol a in Σ:
 5. p ← δ(q, a)
 6. λ'(q, a) ← λ(p) // output of destination state
 7. RETURN M' = (Q', Σ', Δ', δ', λ', q₀')

Manually Validated Example

This is the canonical example from the assignment brief. Verified by hand:

Moore machine:
Q={A,B,C}, Σ={0,1}, Δ={0,1}, q₀=A
λ: A→0, B→1, C→0
δ: A,0→A; A,1→B; B,0→C; B,1→A; C,0→B; C,1→C

Mealy result (applying λ'(q,a)=λ(δ(q,a))):
A,0→A / out λ(A)=0
A,1→B / out λ(B)=1
B,0→C / out λ(C)=0
B,1→A / out λ(A)=0
C,0→B / out λ(B)=1
C,1→C / out λ(C)=0

Validation with w="101":
Moore path: A→B→C→C
Moore outputs: λ(A)·λ(B)·λ(C)·λ(C) = 0·1·0·0 = "0100" (n+1=4)
Mealy outputs: 1·0·0 = "100" (n=3)
Check: MooreOutput[1:] = "100" = MealyOutput ✓
✓ The simulator produces exactly this result when the canonical example is loaded. Verified programmatically by the test suite.

Validation Checks Implemented

✕ ERRORS (block conversion): empty states/alphabet/outputs, no initial state, state without output, invalid output symbol, transition to unknown state, nondeterminism
⚠ WARNINGS (advisory): missing transitions (incomplete δ), unreachable states, unused output symbols
