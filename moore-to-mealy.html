Algorithm Pseudocode
ALGORITHM MooreToMealy(M) Q' ← Q; Σ' ← Σ; Δ' ← Δ; q0' ← q0; δ' ← δ CREATE empty table λ' FOR each state q in Q: FOR each symbol a in Σ: p ← δ(q, a) λ'(q, a) ← λ(p) // output of destination RETURN M'
