1. Moore Machine — Formal Definition

A Moore machine is a finite-state transducer where the output depends only on the current state (not on the input symbol).

M = (Q, Σ, Δ, δ, λ, q₀)

Q — finite, non-empty set of states
Σ — finite input alphabet
Δ — finite output alphabet
δ — transition function: Q × Σ → Q
λ — output function: Q → Δ   (output depends on STATE only)
q₀ — initial state, q₀ ∈ Q

For an input string w = a₁a₂…aₙ, the Moore machine visits states q₀,q₁,…,qₙ where qᵢ = δ(qᵢ₋₁, aᵢ). The output string is λ(q₀)λ(q₁)…λ(qₙ) — of length n+1.

2. Mealy Machine — Formal Definition

A Mealy machine is a finite-state transducer where the output depends on both the current state AND the current input symbol.

M' = (Q, Σ, Δ, δ, λ', q₀)

Q, Σ, Δ, δ, q₀ — same as above
λ' — output function: Q × Σ → Δ   (output depends on STATE and INPUT)

For input w = a₁a₂…aₙ, the Mealy output is λ'(q₀,a₁)λ'(q₁,a₂)…λ'(qₙ₋₁,aₙ) — of length n.

3. Moore vs Mealy — Key Differences

PropertyMoore MachineMealy Machine
Output function domainStates only: λ: Q → ΔState × Input: λ': Q × Σ → Δ
Output length for input |w|=nn + 1 (includes λ(q₀))n
Where output appearsOn nodes/statesOn edges/transitions
Number of states after conversionSame — no extra states needed (Moore→Mealy)
Complexity of conversionO(|Q| · |Σ|)
Expressive powerEquivalent — any Moore machine can be converted to Mealy and vice versa

The key equivalence: MealyOutput(w) = MooreOutput(w)[1:] — the Mealy output is the Moore output with the first symbol (the initial state's output) dropped.

4. Conversion Algorithm

Rule

For every transition δ(q, a) = p in the Moore machine:
  Set λ'(q, a) = λ(p)

That is: the Mealy output on edge (q, a) equals the Moore output of the DESTINATION state p.

Pseudocode

ALGORITHM MooreToMealy(M = (Q, Σ, Δ, δ, λ, q₀))

 1.  Q' ← Q
 2.  Σ' ← Σ
 3.  Δ' ← Δ
 4.  q₀' ← q₀
 5.  δ' ← δ
 6.  Create empty table λ': Q × Σ → Δ
 7.  FOR each state q in Q:
 8.     FOR each symbol a in Σ:
 9.       p ← δ(q, a)
10.       λ'(q, a) ← λ(p) ← output of destination
11.  RETURN M' = (Q', Σ', Δ', δ', λ', q₀')

Time complexity: O(|Q| · |Σ|) — one operation per (state, symbol) pair.

Important: The resulting Mealy machine has the same state set Q. No state splitting or merging is required. This is simpler than the reverse direction (Mealy → Moore), which may require state splitting.

5. The n vs n+1 Output Property

This is the most important property to understand and is explicitly tested in the simulator.

Moore: outputs λ(q₀) before reading any input, then one output per transition.
Mealy: produces output only on transitions — no output for empty input.
Moore output for w = a₁a₂…aₙ:
  λ(q₀) · λ(q₁) · … · λ(qₙ)   (length n+1)

Mealy output for w = a₁a₂…aₙ:
  λ'(q₀,a₁) · λ'(q₁,a₂) · … · λ'(qₙ₋₁,aₙ)   (length n)

Equivalence: MealyOutput = MooreOutput[1:]
  (Moore output with the FIRST symbol dropped)

For empty string ε: Moore outputs λ(q₀); Mealy outputs ε (nothing).

7. Complexity

Conversion time
O(|Q| · |Σ|)
Conversion space
O(|Q| · |Σ|)
State count change
0 (unchanged)

Moore → Mealy is the easy direction: state count stays the same, and the algorithm is a simple table lookup. Mealy → Moore is harder and may require state splitting, potentially multiplying the state count by |Δ|.

8. Correctness Sketch

Claim: For any input string w, the Moore machine M and the constructed Mealy machine M' satisfy: MealyOutput(w) = MooreOutput(w)[1:].

Proof sketch: Let w = a₁a₂…aₙ and let q₀,q₁,…,qₙ be the state sequence in M (same in M' since δ'=δ).

  • Moore output = λ(q₀) · λ(q₁) · … · λ(qₙ)
  • By construction: λ'(qᵢ₋₁, aᵢ) = λ(δ(qᵢ₋₁, aᵢ)) = λ(qᵢ) for i = 1…n
  • Mealy output = λ'(q₀,a₁) · λ'(q₁,a₂) · … · λ'(qₙ₋₁,aₙ) = λ(q₁) · λ(q₂) · … · λ(qₙ)
  • This equals MooreOutput with the first symbol λ(q₀) dropped. ∎

9. Common Mistakes

⚠ Wrong output state: Using λ(q) (source state) instead of λ(p) = λ(δ(q,a)) (destination state). Always use the destination.
⚠ Forgetting the initial output: When comparing Moore and Mealy outputs, remember Moore has one extra symbol at the start. MealyOutput ≠ MooreOutput — they differ by exactly λ(q₀).
⚠ Confusing this with Mealy→Moore: Moore→Mealy needs no extra states. Mealy→Moore is the reverse and may require state splitting.
⚠ Empty string: Moore outputs λ(q₀) for ε input. Mealy outputs nothing (empty string). Handle this case explicitly.
